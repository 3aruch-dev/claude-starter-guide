## How to use this guide

This guide assumes **no technical background**. Every step tells you exactly what to click or type, and why. Go in order the first time; later, jump to what you need.

The guide has two layers:

- **The Foundations (Parts 1–4):** things that rarely change, like opening a terminal and installing Claude Code.
- **The Living Toolkit (Part 6):** the best current tools, skills and MCP servers. This part changes often and is reviewed regularly.

When you see a box like this, type it exactly as shown, then press **Enter**. (Use the copy button in its top-right corner to avoid typos.)

```text
example command
```

Where Mac and Windows steps differ, you'll see tabs like **Mac | Windows**. Pick yours once and the whole guide remembers it.

:::tip
Commands and install steps change over time. If something doesn't match what you see, check the official link given in that section. That link is always the source of truth.
:::

## How this guide stays current

This guide lives in a GitHub repository. A scheduled job runs Claude Code weekly to check the [official sources in 6.1](/claude-starter-guide/part-6-living-toolkit/#61-official-sources-to-follow-check-these-first) for changes, then proposes updates as a pull request. A human reviews and approves every change before it goes live. The Foundations (Parts 1–4) change rarely; the Living Toolkit (Part 6) changes often.

*Have a suggestion? [Open an issue on the guide's GitHub repo](https://github.com/3aruch-dev/claude-starter-guide/issues).*
