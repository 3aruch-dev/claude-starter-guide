---
title: 'Part 7: Your first-week checklist'
description: Nine things to tick off in your first week with Claude Code, from installing your tools to building and pushing your first project.
---

- [ ] GitHub and Claude accounts created
- [ ] Package manager, Git, gh, Node and VS Code installed
- [ ] Claude Code installed and logged in
- [ ] Global `~/.claude/CLAUDE.md` written with your preferences
- [ ] First project built, committed and pushed to GitHub
- [ ] Used Plan mode, `/clear` and `/init` at least once
- [ ] One MCP server added (start with Context7 or Playwright)
- [ ] One custom skill or slash command created
- [ ] Codex installed and used to review something Claude built
