---
title: 'Part 0: Key words in plain English'
description: Terminal, package manager, Git, GitHub, MCP, skills and CLAUDE.md — the words you'll meet in this guide, explained simply.
---

- **Terminal (Mac) / PowerShell (Windows):** a window where you type instructions to your computer instead of clicking. It looks scary, but you only need a few commands.
- **Command:** a line of text you type into the terminal.
- **Package manager:** an app store for the terminal. It installs tools for you. Mac uses **Homebrew**; Windows uses **winget**.
- **Node.js and npm:** Node runs JavaScript programs on your computer; npm installs them. Many AI tools need them.
- **Git:** software that saves every version of your work, like unlimited undo for whole projects.
- **GitHub:** a website that stores your Git projects online, so you can back them up and share them.
- **Repository (repo):** a project folder tracked by Git.
- **Claude Code:** Anthropic's AI agent that works inside your terminal. It can read files, write code, run commands and build things for you.
- **Codex:** OpenAI's similar terminal-based coding agent.
- **MCP (Model Context Protocol):** a standard way to plug extra abilities into AI tools, like access to your calendar, a database or a browser.
- **Skill:** a packaged set of instructions and files that teaches Claude how to do a specific task well.
- **CLAUDE.md:** a text file in your project that tells Claude Code the rules, context and preferences for that project. Think of it as Claude's onboarding document.
